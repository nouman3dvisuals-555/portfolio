# N3D Portfolio — Frontend

Official 3D Product Visualization & Motion Portfolio client application built with React, Vite, Tailwind CSS, and Framer Motion.

## Features
- **3D Portfolio Gallery**: Responsive 4-column layout on desktop, adapting seamlessly to mobile and tablet.
- **Interactive Media Playback**: Inline video playback on click and full theater modal with HTML5 controls.
- **Dynamic Filtering & Pagination**: Category filters and 8-item pagination per section.
- **Admin CMS Integration**: Full CRUD for 3D visual renders and motion projects.

## Tech Stack
- **Framework**: React 18 + Vite
- **Styling**: Tailwind CSS + Custom Design System
- **Icons**: Lucide React
- **API**: Axios with JWT Interceptors + EmailJS contact form

## Getting Started
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
```
