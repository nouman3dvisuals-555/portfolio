# Auto-Push to Respective Repositories Rule

Whenever any changes are finalized and verified in this workspace:
- **Frontend changes (`client/`)** must be committed and pushed to `https://github.com/nouman3dvisuals-555/frontend.git` (`origin main`).
- **Backend changes (`server/`)** must be committed and pushed to `https://github.com/nouman3dvisuals-555/backend.git` (`origin main`).
- Check that `.env` files are never committed.
